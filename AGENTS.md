## Agent skills

For a requested skill, read its supplied path first; otherwise try `.agents/skills/<name>/SKILL.md` before searching other configured skill roots. This includes user-invoked skills absent from the active skill catalog.

### Issue tracker

Issues and specs live in this repository's GitHub Issues. Before issue/spec work or PR closeout, read `docs/agents/issue-tracker.md` for queries and acceptance-checklist synchronization.

### Triage labels

Use the five default triage labels. Before assigning triage labels, read `docs/agents/triage-labels.md`.

### Domain docs

Single-context layout: root `GLOSSARY.md` and `docs/adr/`. Before exploring or changing the codebase, read `docs/agents/domain.md`.
